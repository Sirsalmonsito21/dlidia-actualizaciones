# D'Lidia y David · Actualizaciones

Este repositorio **solo publica los instaladores** del sistema de D'Lidia y David Spa & Salon (sección *Releases*).
No contiene código fuente, datos de clientas ni configuraciones del salón.

- El sistema instalado consulta aquí si hay una versión nueva, la descarga por HTTPS,
  verifica su huella (SHA-512) y la instala al cerrarse.
- Los datos del salón viven únicamente en su propia computadora.
